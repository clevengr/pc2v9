This folder contains the configuration for a "point scoring" contest comprising three problems: a, b, and c.

Problem 'a' has the following attributes:
  - contains secret test data only at the "root" level -- i.e., no scoring subgroups. 
  - contains two test data cases.
  - uses "sum" aggregation; i.e. the score for a submission for problem 'a' is the sum of its scores for each of the two test cases.
